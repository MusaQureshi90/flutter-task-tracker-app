# 📱 Flutter Task Tracker & To-Do Application

A modern, responsive, offline-first task management mobile application engineered using **Flutter**, **Dart**, and **Provider State Management**. Features session persistence, dark/light dynamic theming, and local JSON serialization via **SharedPreferences**.

---

## ✨ Features

* **State Management:** Reactive and modular application state using `Provider` (`ChangeNotifier`).
* **Local Persistence:** Offline-first architecture preserving tasks and auth state across app restarts using `SharedPreferences`.
* **Dynamic Theming:** Smooth toggle between Light and Dark Material 3 color schemes.
* **Task Operations:** Create, complete (toggle with strike-through UI), dismiss/delete, and bulk clear completed tasks.
* **Form Validation:** Client-side email and credential validation for seamless authentication flow.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Flutter (Material 3)
* **Language:** Dart
* **State Management:** `provider`
* **Local Storage:** `shared_preferences`

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/MusaQureshi90/flutter-task-tracker-app.git
cd flutter-task-tracker-app
```

### 2. Install Dependencies
```bash
flutter pub get
```

### 3. Run Application
```bash
flutter run
```
